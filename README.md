## House Rules

```text
01. Local-first by default   — if it can run in the browser or CLI without a backend, it should.
02. Tests prove the fix      — every bugfix starts with a failing regression test on unchanged main.
03. Small, sharp tools       — solve one real workflow cleanly rather than shipping a bloated suite.
04. Build in public          — readable diffs, honest validation notes, and automated telemetry.
```

<details>
<summary><strong>Architecture &amp; Rust live telemetry engine</strong></summary>
<br>

- **18 Custom Theme-Adaptive SVGs** — Pure CSS keyframe animations (GitHub-safe, zero JS, instant dark/light switching via `<picture>`).
- **[`Cargo.toml`](./Cargo.toml) &amp; [`src/main.rs`](./src/main.rs)** — Compiled **Rust 2024 edition** telemetry generator (`ureq 3.5` with pure-Rust `rustls`, `serde`, `chrono`, and built-in `cargo test` unit tests) querying the GitHub REST API for live repos, stars, followers, open PRs, language ratios, and the **14-day public event cadence sparkline**.
- **[`scripts/update-profile.workflow.yml`](./scripts/update-profile.workflow.yml)** — Daily scheduled GitHub Action (`06:00 UTC`) with Cargo caching (`Swatinem/rust-cache@v2`) that runs `cargo test` + `cargo run --release` and commits updated SVGs only on diff.

</details>
